# Jumpscare Webpage (Heartstopper Remake)

https://github.com/akulsaju/heartstopper （ReemanS/heartstopper）の画像と音声をそのまま使用した、ジャンプスケアWebサイトです。

現代のブラウザ（Chrome, Safari, iOS, Android 等）の**「事前の画面タップ/クリックなしでの音声再生を禁止するセキュリティ制限（Autoplay Policy）」**を考慮し、相手が警戒せずに画面をタップした瞬間に**爆音の叫び声 ＋ ジェフ・ザ・キラーのホラー画像が同時に炸裂する**ように設計されています。

---

## 🌟 仕組みと特徴

1. **爆音と画像が「完全同時」に発動**:
   以前のように「画像だけ無音で先に出てしまう」ことがなく、相手が画面をタップしたその瞬間に、ブラウザの音声制限が解除され、**叫び声とホラー画像が同時にドカーン！と直撃**します。
2. **思わずタップしてしまうトラップ画面**:
   - デフォルトは「動画再生ボタン（▶）」。誰でも動画を見ようとして画面をタップします。
   - 画面のボタン上だけでなく、**画面全体のどこをタップしても即座に発動**します。
3. **参考元（heartstopper）の素材を100%使用**:
   - ホラー画像: `assets/jumpscareImage.jpg` (Jeff the Killer)
   - 叫び声音声: `assets/jumpscareSound.mp3`

## ⚙️ URLパラメータ（仕掛けの切り替え）

URLの末尾にパラメータを付与することで、トラップの見た目や挙動を自由に変更できます。

| パラメータ | 説明 | 例 |
|---|---|---|
| `trap=play` | **（デフォルト）** 動画再生風の「▶ Tap to play」画面 | `?trap=play` |
| `trap=heartstopper` | 参考元と同じ「HEARTSTOPPER / Start the Experience」画面 | `?trap=heartstopper` |
| `trap=blank` | 画面が真っ黒。相手が「あれ？」と思って画面を触った瞬間に発動 | `?trap=blank` |
| `direct=true` | 最初から画像を表示するモード（タップで音声開始） | `?direct=true` |
| `title=...` | タブやブラウザバーのタイトルを変更 | `?title=面白い動画見つけた` |

**おすすめの共有リンク例**:
```
https://<username>.github.io/<repo>/?title=おすすめの動画
```
（タイトルが「おすすめの動画」になり、開くと動画再生ボタンが表示され、タップした瞬間に爆音ジャンプスケアが発動します）
